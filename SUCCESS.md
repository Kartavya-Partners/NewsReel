## 🔧 Configuration Tips

**For Faster Performance:**
Edit `config/settings.yaml`:
```yaml
llm:
  model: "mistral"  # Faster than llama3
  max_tokens: 500   # Shorter = faster
  
content:
  summary_length: 100  # Reduced
  target_duration: 60  # 1 minute
```

**For Better Results:**
```yaml
news:
  max_articles: 10  # More content
  
content:
  summary_length: 200  # More detailed
```
